# School ERP System

A multi-school ERP system for district-level school management.

## Features
- Student Management
- Attendance System
- Budget Tracking
- Role-Based Login
- District Dashboard

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication

## Future Plans
- SMS Alerts
- AI Chatbot
- Hindi + English Support
- UDISE+ Integration
